# 임장노트 화면 상태 매트릭스

## 0. 문서 위치와 책임

이 문서는 IA가 정의한 화면 ID(D-001~D-012)에 공통 상태 taxonomy를 적용하고, 화면별 필수 상태와 복구 경로를 정의한다. 상태는 단순 문구가 아니라 사용자가 다음 행동을 결정할 수 있는 UI로 표현한다. 새 화면/상태를 발명하지 않는다.

## 1. 상태 설계 원칙

1. 상태는 항상 "원인 + 다음 행동"을 함께 제시한다.
2. 상태를 색만으로 전달하지 않는다(아이콘·텍스트 병행, NFR-005).
3. 오프라인/동기화 상태는 전역 C-013 SyncStatusBadge로 일관되게 노출한다.
4. 작성/전송 데이터는 어떤 상태에서도 유실되지 않는다(FR-SYNC-001/002).

## 2. 공통 상태 분류(taxonomy)

| 상태 | 의미 | 필수 UI |
| --- | --- | --- |
| loading_initial | 최초 데이터 로딩 | skeleton 또는 progress |
| empty | 표시할 데이터 없음 | 원인과 다음 액션 |
| stale | 캐시 최신성 낮음 | refresh 안내(C-013) |
| no_permission | 워크스페이스/역할 권한 없음 | 필요한 권한과 요청 경로 |
| auth_expired | 인증 만료 | 재인증 액션(D-001) |
| offline | 연결 없음 | 사용 가능 범위와 재시도(C-013) |
| operation_pending | 저장/업로드/동기화 진행 | 진행 표시·취소 가능 여부(C-013) |
| partial_failure | 일부 실패 | 성공/실패 분리·부분 재시도 |
| recoverable_error | 복구 가능 오류 | retry 또는 대체 경로 |
| unrecoverable_error | 복구 불가 오류 | 영향과 지원 경로(로컬 데이터 보존) |

| D-001 온보딩/로그인 | ● | ○ | - | ● | ● | ● | ● | - | ● | 재인증·재시도, 워크스페이스 생성/참여 재진입 |
| D-002 지도 홈 | ● | ● | ● | ○ | - | ● | - | - | ● | 위치권한 폴백, 영역 재조회, 캐시 안내 |
| D-003 단지 상세 | ● | ● | ● | ○ | - | ● | - | ● | ● | 데이터 재조회(F-005), 부분 표시(FR-DATA-003) |
| D-004 노트 작성/편집 | ● | ○ | ● | ● | - | ● | ● | ● | ● | 로컬 임시저장 유지, 동기화 재시도(F-003), 충돌 선택 |
| D-005 피드 | ● | ● | ● | ○ | - | ● | ● | ● | ● | 실시간 재연결, 동기화 대기 항목 재시도 |
| D-006 단지 비교 | ● | ● | ● | ○ | - | ● | - | ● | ● | 대상 추가, 누락 셀 명시, 재조회 |
| D-007 검색/필터 | ● | ● | ● | ○ | - | ● | - | - | ● | 조건 완화, 재조회, 캐시 범위 안내 |
| D-008 즐겨찾기/후보 | ● | ● | ○ | ○ | - | ● | - | ○ | ● | 지도에서 추가, 재조회 |
| D-009 워크스페이스/공유 | ● | ● | - | ● | - | ● | ● | - | ● | 초대 재발송, 권한 안내, 재시도 |
| D-010 알림 센터 | ● | ● | ○ | ○ | - | ● | - | - | ● | 재조회, 딥링크 폴백(F-008) |
| D-011 설정/계정 | ● | ○ | - | ○ | ○ | ● | ● | - | ● | 설정 저장 재시도, 재인증 |
| D-012 노트 상세/코멘트 | ● | ● | ● | ○ | - | ● | ● | ● | ● | 코멘트 큐 재전송, 사진 부분 재로드, 폴백 |

비고:
- auth_expired는 모든 화면에서 발생 가능하나 처리는 전역 인증 게이트가 D-001로 라우팅한다(표에서는 직접 노출이 핵심인 화면만 ●).
- unrecoverable_error는 전역으로 가능하며, 발생 시 영향 안내와 지원 경로를 제공하고 로컬 작성/큐 데이터는 보존한다.

## 4. 상태별 복구 경로 상세

### offline / stale (전 화면 공통)

- C-013로 상태 노출. D-002/D-003/D-006/D-007은 캐시 데이터 우선 표시, 신규 조회 제한 명시.
- D-004/D-005/D-012 작성·코멘트는 로컬 큐 보존, 온라인 복귀 시 자동 동기화(F-003).

### operation_pending (동기화중)

- D-004 저장/사진 업로드, D-005 동기화, D-009 초대 처리, D-012 코멘트 전송, D-011 설정 저장에서 진행 표시.
- 가능 시 취소/백그라운드 진행 허용. 완료/실패는 명시적 결과 표시.

### partial_failure

- D-003/D-006: 공공데이터 일부(실거래가 등) 누락 분리 표시(FR-DATA-003 저하 모드).
- D-004/D-005/D-012: 본문 성공·사진/일부 항목 실패 분리, 실패분만 재시도.

### no_permission

- D-009: 비소유자 관리 액션 차단·사유 안내.
- 딥링크(F-008)로 타 워크스페이스 자원 접근 시 차단.

### recoverable_error / unrecoverable_error

- recoverable: retry 버튼·대체 경로 제공.
- unrecoverable: 영향 범위·지원 경로 안내, 작성/큐 데이터는 절대 폐기하지 않음(NFR-004).
