# 임장노트 화면 플로우 명세서

## 0. 문서 위치와 책임

이 문서는 SRS의 플로우(F-001~F-008)를 화면 전환·모달/시트/풀스크린 규칙·딥링크·성공/실패/오프라인/예외 경로로 상세화한다. 화면 ID(D-*)·컴포넌트(C-*)·요구사항(FR-*)은 IA·SRS 정의를 따른다. 새 흐름을 발명하지 않는다.

## 1. 전환 규칙(공통)

- 전환은 사용자의 현재 컨텍스트(지도 위치, 작성 중 노트, 스크롤 위치)를 보존한다.
- 실패 전환은 원인·영향·복구 경로를 화면 상태로 표시한다(상태 매트릭스 참조).
- 모달/시트/풀스크린은 뒤로가기(안드로이드 하드웨어 백 포함) 동작을 정의한다.
- 작성 중(D-004) 이탈 시 임시저장 확인을 거쳐 데이터 유실을 막는다(FR-SYNC-001).

## 2. 표면 전환 규칙

| 표면 유형 | 사용 화면 | 백/닫기 동작 |
| --- | --- | --- |
| 탭 전환 | D-002/D-005/D-008/D-010/D-011 | 탭 상태 보존, 백 시 직전 탭/종료 가드 |
| push 스택 | D-003/D-006/D-009/D-012 | 백 → 직전 화면, 컨텍스트 보존 |
| 풀스크린 | D-004 | 닫기 → 임시저장 확인 후 복귀 |
| 하단 시트 | D-002의 C-003 미리보기, D-007 필터 C-009 | 스와이프/백 → 시트 닫힘(데이터 보존) |
| 시트 또는 풀스크린 | D-007 검색 | 진입 표면에 따라 닫힘 규칙 적용 |

## 3. Deeplink 규칙(공통)

- 대상 없음: not_found 상태 + 안전 폴백(목록/지도)으로 이동.
- 권한 없음(타 워크스페이스): no_permission 상태.
- 인증 만료: auth_expired → D-001 재인증 후 원래 대상 복귀.
- 오프라인: 캐시 가능 범위 표시 후 온라인 복귀 시 재시도.

## F-001 지도 → 단지 클릭 → 노트 작성

핵심 가치 경로. 가장 짧은 경로로 작성에 도달한다.

### 성공 경로

1. D-002 지도 홈에서 마커/클러스터 탐색(FR-MAP-001~003).
2. `marker.select`(FR-MAP-004) → 하단 시트로 C-003 미리보기.
3. `card.openDetail` → D-003 단지 상세 push(FR-DATA-001~002 로딩).
4. `note.create`(FR-NOTE-001) → D-004 풀스크린 작성.
5. C-008에서 별점(FR-NOTE-001)·체크리스트(FR-NOTE-002)·사진(FR-MEDIA-001)·본문(FR-NOTE-004) 입력.
6. `note.save`(FR-NOTE-006) → 저장 성공 → D-003 또는 D-005 피드 반영.

### 실패 경로

- 단지 데이터 로드 실패: D-003 recoverable_error, 재시도/부분 표시(FR-DATA-003).
- 저장 실패: D-004 recoverable_error, 로컬 임시저장 유지 후 재시도.

### 오프라인 경로

- 캐시된 단지면 상세 열람 가능. 작성은 가능, 저장은 로컬 큐(F-003로 연결).

### 예외

- 위치 권한 없음(no_permission): 수동 영역 탐색 폴백.
- 단지정보 없음(empty): 작성은 단지 컨텍스트 한도 내 허용 또는 안내.

## F-002 워크스페이스 초대/수락

### 성공 경로

1. D-009에서 `invite.create`(FR-WS-002) → 초대 링크/코드 생성·공유.
2. 상대가 초대 링크(딥링크) 진입.
3. 미인증이면 D-001 → 인증(FR-AUTH-001~003) 후 수락 단계 복귀.
4. `invite.accept`(FR-WS-002) → 워크스페이스 합류, D-009 멤버 목록(C-015) 갱신.

### 실패 경로

- 초대 만료/무효: not_found 또는 recoverable_error, 새 초대 요청 안내.
- 멤버 상한 초과(부부 2인): no_permission/정책 안내(FR-WS-*).

### 오프라인 경로

- 수락 처리는 온라인 필요. 오프라인 시 대기 후 재시도 안내.

### 예외

- 비소유자가 관리 액션 시도: no_permission(D-009).

## F-003 오프라인 작성 → 동기화

신뢰성 핵심 경로(FR-SYNC-001/002, NFR-004).

### 성공 경로

1. 오프라인 상태에서 D-004 작성, `note.draftSave`로 로컬 저장(C-013 offline 표시).
2. 사진은 로컬 큐(FR-MEDIA-001).
3. 온라인 복귀 감지 → `sync.enqueue`/자동 동기화 시작(operation_pending, C-013 동기화중).
4. 성공 → D-005 피드 반영(FR-SYNC-002), C-013 정상.

### 실패/부분 실패 경로

- 본문 성공·사진 일부 실패: partial_failure, 실패 항목만 재시도(`sync.retry`).
- 충돌(원격 변경 존재): stale 안내, 사용자 선택(내 변경 유지/원격 반영) 경로 제공.

### 예외

- 장기 오프라인: 큐 누적 표시, 데이터 유실 없이 보존.
- 복구 불가 오류: unrecoverable_error, 영향·지원 경로 표시(로컬 데이터는 보존).

## F-004 코멘트

### 성공 경로

1. D-012 노트 상세 진입(딥링크 F-008 포함).
2. C-007 CommentThread에서 `comment.add`(FR-COMMENT-001).
3. Realtime로 상대에게 반영, 알림 생성(FR-NOTIFY-001).

### 실패/오프라인 경로

- 오프라인: 코멘트 로컬 큐(operation_pending), 온라인 복귀 시 전송(F-003 연계).
- 전송 실패: recoverable_error, 재시도.

### 예외

- 노트 삭제됨: not_found, 목록으로 폴백.
- 타 워크스페이스 노트: no_permission.

---

## F-005 실거래가 조회

### 성공 경로

1. D-003에서 `price.load`(FR-DATA-002) → C-014 PriceHistoryChart 렌더.
2. 캐시 우선, 필요 시 Edge Function 프록시 조회(NFR-001).

### 실패/저하 경로

- 조회 실패: partial_failure(단지정보는 유지), 재시도.
- 데이터 부분 누락: 저하 모드(FR-DATA-003) 안내, 누락 구간 명시.
- stale: 갱신 버튼(`data.refresh`).

### 오프라인 경로

- 캐시된 추이만 표시, 신규 구간 조회 제한 안내.

---

## F-006 검색·필터

### 성공 경로

1. D-002 C-010 `search.open`(FR-SEARCH-001) → D-007(시트/풀스크린).
2. `search.query`/`filter.apply`(FR-SEARCH-002) → 결과 리스트(FR-DATA-004 조회).
3. `result.openComplex` → D-003 또는 `result.showOnMap` → D-002 반영.

### 실패/빈 경로

- 결과 없음: empty, 조건 완화 제안.
- 조회 실패: recoverable_error, 재시도.

### 오프라인 경로

- 캐시 기반 결과만, 범위 안내(stale/offline).

---

## F-007 비교

### 성공 경로

1. D-008에서 후보 다중 선택(FR-FAV-002, 최소 2개) → `compare.start` → D-006.
2. C-011 CompareTable에 속성·실거래가(FR-DATA-002)·별점(FR-NOTE-003) 표시.
3. 칩으로 대상 추가/제거(`compare.addComplex`/`removeComplex`).

### 실패/빈 경로

- 대상 1개 이하: empty, 추가 안내.
- 일부 단지 데이터 누락: partial_failure, 누락 셀 "데이터 없음".

### 오프라인 경로

- 캐시 범위 내 비교만.

---

## F-008 알림 딥링크

### 성공 경로

1. Expo Notifications 푸시 또는 D-010 알림 탭(FR-NOTIFY-001).
2. `notify.openTarget` → 대상 화면 push:
   - 코멘트 알림 → D-012(F-004).
   - 초대 알림 → D-009(F-002).
   - 동기화/피드 알림 → D-005.

### 예외 경로

- 대상 없음: not_found, 안전 폴백(D-005/D-002).
- 권한 없음: no_permission.
- 인증 만료: auth_expired → D-001 재인증 후 대상 복귀.
- 오프라인: 캐시 가능 시 열람, 아니면 복귀 후 재시도.

## 4. 공통 예외 흐름 요약

| 예외 | 의미 | 처리 |
| --- | --- | --- |
| not_found | 대상 없음/삭제 | 안전 폴백 + 사유 |
| no_permission | 워크스페이스/역할 권한 없음 | 필요한 권한·요청 경로 |
| auth_expired | 세션 만료 | D-001 재인증 후 복귀 |
| offline | 연결 없음 | 캐시 범위 안내·재시도 |
| partial_failure | 일부 실패 | 성공/실패 분리·부분 재시도 |
| recoverable_error | 복구 가능 | retry/대체 경로 |
| unrecoverable_error | 복구 불가 | 영향·지원 경로(로컬 데이터 보존) |
