# 임장노트 화면 QA 체크리스트

## 0. 문서 위치와 책임

이 문서는 IA·와이어프레임·플로우·상태 매트릭스·컴포넌트·토큰과 일치하는지 검수하는 수용 게이트다. 실패 항목은 화면 ID(D-*)·요구사항(FR-*)·플로우(F-*)에 연결한다. 새 범위를 검수 항목으로 추가하지 않는다.

## 1. 사용 방법

- 구현 후 화면별로 체크하고, 실패 항목은 요구사항 또는 화면 ID에 연결한다.
- 릴리스 전 공통·회귀·접근성·비정상 흐름·릴리스 게이트를 모두 통과해야 한다.

## 2. 공통 검수 항목 (전 화면)

- [ ] 탭 셸(지도/피드/즐겨찾기/알림/설정) 이동이 동작하고 인증 게이트가 적용된다.
- [ ] 상태 taxonomy(loading/empty/stale/no_permission/auth_expired/offline/operation_pending/partial_failure/recoverable/unrecoverable)가 해당 화면에 구현된다(상태 매트릭스 일치).
- [ ] 권한/정책으로 비활성화된 액션이 사유를 표시한다(no_permission).
- [ ] 파괴적 액션(노트/코멘트 삭제, 멤버 제거)에 확인·복구 경로가 있다.
- [ ] 상태/등락/별점을 색만으로 전달하지 않는다(아이콘·텍스트 병행, NFR-005).
- [ ] 터치 타깃 44pt 이상, 주요 액션이 한 손 도달 영역에 있다.
- [ ] 오프라인/동기화 상태가 C-013로 일관되게 노출된다(FR-SYNC-001/002).
- [ ] 텍스트·컨트롤이 겹치지 않고 동적 글꼴 크기를 견딘다.
- [ ] 작성/전송 데이터가 어떤 상태에서도 유실되지 않는다.

## 3. 화면별 체크리스트

### D-001 온보딩/로그인

- [ ] 인증 성공/실패(FR-AUTH-001~003)와 재인증(auth_expired)이 처리된다.
- [ ] 워크스페이스 생성(FR-WS-001)/초대 수락(FR-WS-002, F-002) 분기가 동작한다.
- [ ] 개인정보 고지·동의 경로가 있다(NFR-003).

### D-002 지도 홈

- [ ] 지도 이동/줌/영역 로드(FR-MAP-001/002/005)가 동작한다.
- [ ] 마커·클러스터·노트 핀(FR-MAP-003/004, FR-NOTE-005)이 표시·선택된다.
- [ ] 단지 선택 → C-003 미리보기 → D-003(F-001)로 이어진다.
- [ ] 검색 진입(FR-SEARCH-001 → D-007), 위치 권한 거부 폴백이 동작한다.
- [ ] 빈 영역/오프라인/stale 상태가 안내된다.

### D-003 단지 상세

- [ ] 단지정보(FR-DATA-001)·실거래가 차트(FR-DATA-002, C-014)가 로드된다.
- [ ] 즐겨찾기 토글(FR-FAV-001), 노트 작성(FR-NOTE-001 → D-004)·열람(→ D-012)이 동작한다.
- [ ] 저하 모드/부분 실패(FR-DATA-003)가 분리 표시된다.

### D-004 노트 작성/편집

- [ ] 별점(FR-NOTE-001)·체크리스트 6항목(FR-NOTE-002)·구조화 항목(FR-NOTE-003)·본문(FR-NOTE-004)·사진(FR-MEDIA-001)이 입력된다.
- [ ] 저장(FR-NOTE-006)·임시저장·이탈 가드가 동작한다.
- [ ] 오프라인 작성 → 동기화(F-003, FR-SYNC-001), 부분 실패·충돌 경로가 처리된다.

### D-005 노트 목록/워크스페이스 피드

- [ ] 워크스페이스 노트 피드(FR-NOTE-005, FR-WS-003)가 실시간 갱신된다.
- [ ] 동기화 대기/실패 항목(FR-SYNC-002, C-013)이 표시·재시도된다.
- [ ] 항목 → D-012 이동, 빈/오프라인 상태가 처리된다.

### D-006 단지 비교

- [ ] 후보 다중 비교(FR-FAV-002, F-007), 실거래가(FR-DATA-002)·구조화 평가(FR-NOTE-003) 표시.
- [ ] 대상 2개 미만 empty, 누락 셀 "데이터 없음", 가로 스크롤·헤더 고정.

### D-007 검색/필터

- [ ] 검색(FR-SEARCH-001)·필터(FR-SEARCH-002)·조회(FR-DATA-004)가 동작한다.
- [ ] 결과 → D-003/지도 반영, 결과 없음·오프라인 상태 처리.

### D-008 즐겨찾기/후보 리스트

- [ ] 즐겨찾기 목록·제거(FR-FAV-001), 후보 선택·비교 진입(FR-FAV-002 → D-006).
- [ ] 빈 상태가 지도 추가를 유도한다.

### D-009 워크스페이스/공유·초대

- [ ] 멤버 목록(FR-WS-001, C-015), 초대 발송/수락(FR-WS-002, F-002), 관리(FR-WS-004), 계정 연결(FR-AUTH-004).
- [ ] 비소유자 관리 액션 no_permission, 멤버 상한 정책이 적용된다.

### D-010 알림 센터

- [ ] 알림 목록·읽음(FR-NOTIFY-001), 구독(FR-NOTIFY-002).
- [ ] 딥링크(F-008) → D-012/D-009/D-005, not_found/no_permission/auth_expired 폴백.

### D-011 설정/계정/개인정보

- [ ] 계정·로그아웃(FR-AUTH-004), 일반 설정(FR-SET-001), 개인정보 동의(FR-SET-002, NFR-003).
- [ ] 데이터 저하 모드(FR-DATA-003)·관측 동의(NFR-006)가 동작하고 D-002/D-003에 반영된다.

### D-012 노트 상세/코멘트

- [ ] 체크리스트(FR-NOTE-002)·사진 열람(FR-MEDIA-002)·본문(FR-NOTE-004) 표시.
- [ ] 코멘트(FR-COMMENT-001, F-004) 실시간·오프라인 큐, 편집/삭제(FR-NOTE-006).

## 4. 회귀 체크리스트

- [ ] 탭 전환·push 백·시트 닫힘에서 컨텍스트(지도 위치·스크롤·작성 중 노트)가 보존된다.
- [ ] 동일 단지 카드/별점/빈상태/동기화 배지가 모든 화면에서 동일 컴포넌트(C-003/C-004/C-012/C-013)로 렌더된다.
- [ ] 오프라인→온라인 복귀 시 작성/코멘트 큐가 중복 없이 동기화된다.
- [ ] 딥링크 진입이 인증/권한/존재 여부에 따라 일관되게 라우팅된다(F-008).

## 5. 키보드/접근성 체크리스트 (NFR-005)

- [ ] 모든 인터랙티브 요소에 가시적 포커스 표시가 있다.
- [ ] 스크린리더 label·역할(지도 폴백, 별점 값, 체크리스트 항목, 차트 대체 표)이 제공된다.
- [ ] 색 대비 WCAG AA(본문 4.5:1) 충족, 색 외 단서 동반.
- [ ] 동적 글꼴/동작 줄이기 OS 설정을 존중한다.
- [ ] 실시간 코멘트/동기화 변경이 live region으로 announce된다.

## 6. 비정상 흐름 체크리스트

- [ ] 오프라인 작성·동기화 충돌(F-003), 부분 실패가 사용자 선택 경로를 제공한다.
- [ ] 인증 만료 중 작업 시 데이터 보존 후 재인증 복귀.
- [ ] 삭제된 노트/단지/초대 딥링크가 not_found 폴백된다.
- [ ] 공공데이터 저하/지연(FR-DATA-003) 시 누락 구간이 명시된다.
- [ ] 권한 없는 워크스페이스 자원 접근이 차단된다(NFR-002).

## 7. 릴리스 게이트

- [ ] SRS 요구사항(FR-*/NFR-*)과 추적 가능하다(traceability 일치).
- [ ] IA·와이어프레임·플로우·상태 매트릭스·컴포넌트·토큰 간 불일치가 없다.
- [ ] 모든 화면이 P0/P1/P2 우선순위 범위 내에서 구현·검증되었다.
- [ ] 알려진 제한이 문서화되어 있다.
- [ ] 새 화면/기능/범위가 추가되지 않았다(D-/C-/F- ID 고정).
