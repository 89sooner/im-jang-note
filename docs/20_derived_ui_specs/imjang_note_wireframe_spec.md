# 임장노트 와이어프레임 사양서

## 0. 문서 위치와 책임

이 문서는 IA 문서(`imjang_note_product_ia.md`)가 정의한 화면 ID(D-001~D-012)를 화면별로 상세화한다. 화면 ID·컴포넌트 ID·플로우 ID·요구사항 ID는 IA와 SRS에서 정의된 것만 사용하며 새 화면/기능/범위를 만들지 않는다. 화면별 상태의 세부 정의는 `imjang_note_screen_state_matrix.md`, 컴포넌트 세부는 `imjang_note_ui_component_spec.md`, 전환은 `imjang_note_screen_flow_spec.md`를 참조한다.

## 1. 공통 화면 사양 형식

각 화면은 다음 순서를 따른다.

- 화면 목적
- 진입 경로
- 레이아웃 구조
- 섹션 정의
- 주요 컴포넌트(C-*)
- 상태 정의
- 이벤트 정의
- 권한/정책
- 구현 메모

## 2. 컴포넌트 레지스트리(요약)

세부 명세는 `imjang_note_ui_component_spec.md`에 있다. 본 문서는 화면이 사용하는 컴포넌트만 참조한다.

## 3. 공통 상태 분류(참조)

모든 화면은 상태 taxonomy를 공유한다: loading_initial · empty · stale · no_permission · auth_expired · offline · operation_pending(동기화중) · partial_failure · recoverable_error · unrecoverable_error. 화면별 적용은 상태 매트릭스 문서를 따른다.

## D-001 온보딩/로그인

### 화면 목적

진입·인증을 처리하고, 인증 직후 워크스페이스를 생성하거나 초대를 받아 참여하게 한다. 부부 협업의 출발점이다. (FR-AUTH-001~003, FR-WS-001/002)

### 진입 경로

- 앱 콜드 스타트 시 세션 미존재/만료(auth_expired) → 본 화면.
- 인증 게이트에 걸린 모든 탭/딥링크(F-008/F-002)에서 리다이렉트.

### 레이아웃 구조

- 상단: 브랜드/제품 한 줄 소개 영역.
- 중앙: 인증 수단 영역(이메일/소셜 등 SRS 인증 수단 범위 내).
- 하단: 약관/개인정보 고지 링크(NFR-003), 도움말.
- 인증 후 분기 영역: 워크스페이스 생성 / 초대코드(또는 초대 링크)로 참여 선택.

### 섹션 정의

1. 인증 섹션: 로그인/가입(FR-AUTH-001~003).
2. 워크스페이스 진입 섹션: 신규 워크스페이스 생성(FR-WS-001) 또는 초대 수락 참여(FR-WS-002).
3. 정책 고지 섹션: 개인정보 처리·동의(NFR-003).

### 주요 컴포넌트

- C-012 EmptyState(초대 없음/세션 없음 안내), C-015 MemberAvatar(초대 발신자 표시, 초대 수락 컨텍스트).

### 상태 정의

- loading_initial: 세션 확인 중.
- unauthenticated: 미인증(로그인 폼).
- auth_expired: 세션 만료 재인증.
- operation_pending: 인증/워크스페이스 생성/참여 처리 중.
- recoverable_error: 인증 실패·네트워크 오류 재시도.
- offline: 오프라인 시 인증 불가 안내(작성 데이터는 보존, 온라인 복귀 후 처리).

### 이벤트 정의

- `auth.signIn`, `auth.signUp`, `auth.retry`
- `workspace.create`(FR-WS-001), `workspace.acceptInvite`(FR-WS-002)
- `auth.signOut`는 D-011에서 처리.

### 권한/정책

- 인증 전에는 탭 셸·데이터 접근 불가. 워크스페이스 RLS 격리 전제(NFR-002).
- 워크스페이스는 부부 2인 기준 멤버 상한을 따른다(FR-WS-*).

### 구현 메모

- 초대 딥링크 진입은 F-002 흐름으로 연결. 미인증 상태에서 초대 링크 진입 시 인증 후 자동으로 수락 단계로 복귀.

## D-002 지도 홈

### 화면 목적

지도 위에서 단지를 탐색하고, 마커/클러스터·노트 핀을 보고, 검색으로 진입하며, 단지 클릭으로 상세·노트 작성 흐름(F-001)을 시작하는 기본 시작점이다. (FR-MAP-001~005, FR-NOTE-005, FR-SEARCH-001)

### 진입 경로

- 인증 후 기본 탭(탭1). 앱 시작 시 기본 진입.
- 다른 화면의 "지도에서 보기" 액션, 알림 딥링크(F-008).

### 레이아웃 구조

- 전체: C-001 MapView 풀스크린.
- 상단 오버레이: C-010 SearchBar + 전역 C-013 SyncStatusBadge.
- 지도 위: C-002 ComplexMarker/Cluster, 노트가 있는 단지의 노트 핀 표식(FR-NOTE-005).
- 하단: 단지 선택 시 미리보기 C-003 ComplexCard 시트(엄지 도달 영역), "내 위치"·"노트만 보기" 토글.

### 섹션 정의

1. 지도 캔버스(FR-MAP-001 표시, FR-MAP-002 이동/줌, FR-MAP-003 클러스터링).
2. 단지 마커 레이어(FR-MAP-004 단지 선택).
3. 노트 핀 레이어(FR-NOTE-005 노트 보유 단지 표시).
4. 검색 진입(FR-SEARCH-001 → D-007).
5. 현위치/지도 영역 데이터 로드(FR-MAP-005 영역 기반 데이터 조회).

### 주요 컴포넌트

- C-001, C-002, C-003, C-010, C-013, C-012(영역 내 단지 없음/검색 결과 없음).

### 상태 정의

- loading_initial: 지도/단지 데이터 로딩(스켈레톤·진행 표시).
- empty: 현재 지도 영역 내 단지 없음.
- stale: 공공데이터 캐시 최신성 낮음(갱신 안내).
- offline: 지도 타일/공공데이터 조회 제한, 캐시 범위 안내(C-013).
- recoverable_error: 데이터 조회 실패 재시도.
- no_permission: 위치 권한 거부 시 수동 영역 탐색 폴백.

### 이벤트 정의

- `map.move`, `map.zoom`, `map.loadViewport`(FR-MAP-005)
- `marker.select`(FR-MAP-004) → C-003 미리보기
- `card.openDetail` → D-003 push (F-001)
- `search.open`(FR-SEARCH-001) → D-007
- `notePin.toggle`(FR-NOTE-005)

### 권한/정책

- 위치 권한은 선택. 거부 시 기능 저하 폴백 제공.
- 단지/실거래가 데이터는 Edge Function 프록시·캐시 경유(NFR-001/004).

### 구현 메모

- 마커 다수 시 클러스터링으로 성능 유지(NFR-001). 한 손 조작 위해 핵심 컨트롤은 화면 하단 배치.

## D-003 단지 상세

### 화면 목적

선택한 단지의 공공데이터(단지정보·실거래가)를 보여주고, 즐겨찾기 토글과 노트 작성/열람 진입을 제공한다. (FR-DATA-001~004, FR-NOTE-001, FR-FAV-001)

### 진입 경로

- D-002 단지 미리보기 카드 → 상세(F-001).
- D-007 검색 결과, D-008 즐겨찾기, D-005 피드 항목, 딥링크(F-008)에서 push.

### 레이아웃 구조

- 상단: 단지명·주소·핵심 메타(C-003 확장형), 즐겨찾기 토글(FR-FAV-001).
- 본문 1: 단지정보 섹션(FR-DATA-001 단지 상세, FR-DATA-003 데이터 저하/부분 안내).
- 본문 2: 실거래가 추이 C-014 PriceHistoryChart(FR-DATA-002, F-005).
- 본문 3: 이 단지의 노트 목록 진입(FR-NOTE-001 작성 진입 / 기존 노트 → D-012).
- 하단 고정: "노트 작성"(F-001) 기본 액션.

### 섹션 정의

1. 단지 헤더·즐겨찾기(FR-FAV-001).
2. 단지정보(FR-DATA-001).
3. 실거래가(FR-DATA-002, C-014).
4. 관련 데이터 조회/필터 보조(FR-DATA-004 검색·조회 연계).
5. 단지 노트 진입(FR-NOTE-001).

### 주요 컴포넌트

- C-003, C-004(노트 요약 별점 표시), C-014, C-013, C-015(노트 작성자), C-012(노트 없음/거래 데이터 없음).

### 상태 정의

- loading_initial: 공공데이터 로딩.
- stale: 캐시 데이터 최신성 낮음(F-005 재조회 안내).
- partial_failure: 단지정보는 성공·실거래가 실패(또는 반대) 분리 표시.
- offline: 캐시된 단지만 열람, 신규 조회 제한.
- recoverable_error: 조회 실패 재시도.
- empty: 실거래가/노트 없음.

### 이벤트 정의

- `complex.loadInfo`(FR-DATA-001), `price.load`(FR-DATA-002, F-005)
- `favorite.toggle`(FR-FAV-001)
- `note.create`(FR-NOTE-001) → D-004, `note.open` → D-012
- `data.refresh`(stale 갱신)

### 권한/정책

- 워크스페이스 RLS: 노트 목록은 본인 워크스페이스 범위만(NFR-002).
- 공공데이터 저하 모드(FR-DATA-003): 일부 항목 누락 시 사유 표시.

### 구현 메모

- C-014 차트는 데이터 없음/부분 데이터/오프라인 상태를 각각 시각적으로 구분. 색만으로 등락 전달 금지(NFR-005).

## D-004 노트 작성/편집

### 화면 목적

단지에 대한 구조화된 임장 후기를 작성/편집한다. 별점, 체크리스트(교통·학군·소음·채광·관리상태·주변환경), 사진, 메모를 포함하며, 오프라인 작성 후 온라인 복귀 시 동기화한다. (FR-NOTE-001~004/006, FR-MEDIA-001, FR-SYNC-001)

### 진입 경로

- D-003 "노트 작성"(F-001), D-012 "편집"(FR-NOTE-006 수정), D-005 피드의 편집 액션.
- 풀스크린 push(작성 중 이탈 방지).

### 레이아웃 구조

- 상단: 단지 컨텍스트(이름)·닫기·저장/동기화 상태 C-013.
- 본문(C-008 NoteForm 내부):
  - 별점 C-004(FR-NOTE-001 평가).
  - 체크리스트 C-005(FR-NOTE-002 6개 항목).
  - 사진 C-006 PhotoGrid(FR-MEDIA-001 첨부).
  - 자유 메모/세부 평가(FR-NOTE-003 구조화 항목, FR-NOTE-004 본문).
- 하단 고정: 저장(FR-NOTE-006), 임시저장 표시.

### 섹션 정의

1. 평가/별점(FR-NOTE-001).
2. 체크리스트(FR-NOTE-002).
3. 구조화 항목/비교용 속성(FR-NOTE-003).
4. 본문 메모(FR-NOTE-004).
5. 사진(FR-MEDIA-001).
6. 저장·임시저장·동기화(FR-NOTE-006, FR-SYNC-001).

### 주요 컴포넌트

- C-008, C-004, C-005, C-006, C-013, C-012(첨부 없음 안내).

### 상태 정의

- loading_initial: 편집 모드 기존 노트 로딩.
- operation_pending: 저장/업로드/동기화 진행.
- offline: 로컬 임시저장, 동기화 대기 표시(FR-SYNC-001, C-013).
- partial_failure: 본문 저장 성공·사진 업로드 일부 실패 분리 표시.
- recoverable_error: 저장 실패 재시도.
- stale: 동기화 중 원격 변경 충돌 가능성 안내.

### 이벤트 정의

- `note.draftSave`(로컬 임시저장), `note.save`(FR-NOTE-006)
- `checklist.update`(FR-NOTE-002), `rating.set`(FR-NOTE-001)
- `photo.add`/`photo.remove`(FR-MEDIA-001)
- `sync.enqueue`/`sync.retry`(FR-SYNC-001)

### 권한/정책

- 본인 워크스페이스 단지에 한해 작성(RLS, NFR-002).
- 사진은 Storage 업로드, 오프라인 시 로컬 큐(FR-SYNC-001).
- 작성 중 이탈 시 임시저장 확인(데이터 유실 방지, F-003).

### 구현 메모

- 오프라인 작성 → 온라인 복귀 시 자동 동기화(F-003). 충돌 시 사용자 선택 경로 제공(상태 매트릭스 참조).

## D-005 노트 목록/워크스페이스 피드

### 화면 목적

부부가 작성한 노트를 시간순/단지별로 공유하는 피드. 실시간 갱신과 동기화 결과를 보여준다. (FR-NOTE-005, FR-WS-003, FR-SYNC-002)

### 진입 경로

- 탭2(피드). D-003·D-012에서 "피드로" 보조 이동, 알림 딥링크(F-008).

### 레이아웃 구조

- 상단: 정렬/필터(시간순·단지별), 전역 C-013.
- 본문: 노트 카드 리스트(작성자 C-015, 단지명, 별점 C-004 요약, 체크리스트 요약, 동기화 상태).
- 항목 탭 → D-012.

### 섹션 정의

1. 워크스페이스 공유 피드(FR-NOTE-005, FR-WS-003).
2. 동기화 결과/대기 항목(FR-SYNC-002, C-013).
3. 정렬/필터 진입(FR-SEARCH 연계는 D-007에서, 피드 내 간단 정렬은 로컬).

### 주요 컴포넌트

- C-003(노트 컨텍스트 단지), C-004, C-015, C-013, C-012(노트 없음).

### 상태 정의

- loading_initial: 피드 로딩.
- empty: 워크스페이스에 노트 없음(작성 유도).
- operation_pending: 동기화 중 항목 표시(FR-SYNC-002).
- partial_failure: 일부 노트 동기화 실패 분리 표시.
- offline: 캐시 피드 열람, 신규 반영 지연 안내.
- stale: 실시간 연결 끊김 후 재연결 안내.

### 이벤트 정의

- `feed.load`, `feed.realtimeUpdate`(FR-WS-003 실시간 공유)
- `feed.openNote` → D-012
- `sync.statusView`(FR-SYNC-002)

### 권한/정책

- 본인 워크스페이스 노트만(RLS, NFR-002). 멤버 표시(C-015)로 작성자 구분.

### 구현 메모

- Supabase Realtime 구독. 동기화 대기/실패 항목은 C-013로 명시(F-003 결과 가시화).

## D-006 단지 비교

### 화면 목적

후보 단지를 다중 선택해 속성·실거래가·노트 평가를 한 화면에서 비교한다. (FR-FAV-002, FR-DATA-002, FR-NOTE-003)

### 진입 경로

- D-008 즐겨찾기/후보에서 비교 대상 선택 후 진입(F-007). D-003에서 비교 추가.

### 레이아웃 구조

- 상단: 비교 대상 단지 칩(추가/제거), 비교 기준 토글.
- 본문: C-011 CompareTable(행=속성, 열=단지). 실거래가 요약(C-014 미니), 별점 C-004, 체크리스트 항목 비교(FR-NOTE-003 구조화 속성).

### 섹션 정의

1. 비교 대상 관리(FR-FAV-002 후보).
2. 비교 테이블(FR-NOTE-003 구조화 항목 비교).
3. 실거래가 비교(FR-DATA-002).

### 주요 컴포넌트

- C-011, C-004, C-014, C-003(헤더 컨텍스트), C-012(비교 대상 부족 안내).

### 상태 정의

- empty: 비교 대상 0~1개(최소 2개 안내).
- loading_initial: 비교 데이터 로딩.
- partial_failure: 일부 단지 실거래가 누락 분리 표시.
- stale: 캐시 데이터 최신성 낮음.
- offline: 캐시 범위 내 비교만.

### 이벤트 정의

- `compare.addComplex`/`compare.removeComplex`(FR-FAV-002)
- `compare.load`, `compare.sortByMetric`

### 권한/정책

- 노트 평가 비교는 본인 워크스페이스 노트 기반(RLS).

### 구현 메모

- 열 수가 많을 때 가로 스크롤·고정 헤더. 누락 셀은 "데이터 없음" 명시(NFR-005).

## D-007 검색/필터

### 화면 목적

단지·노트를 검색하고 조건으로 필터링한다. (FR-SEARCH-001~002, FR-DATA-004)

### 진입 경로

- D-002 검색바(C-010) → 시트 또는 풀스크린(FR-SEARCH-001). D-005 피드 필터, D-008에서 진입(F-006).

### 레이아웃 구조

- 상단: C-010 SearchBar(쿼리 입력).
- 본문: C-009 FilterSheet(지역·가격대·평형·체크리스트 항목 등 SRS 범위 필터), 결과 리스트(C-003).

### 섹션 정의

1. 검색 입력(FR-SEARCH-001).
2. 필터(FR-SEARCH-002).
3. 데이터 조회 연계(FR-DATA-004).
4. 결과 → D-003 또는 지도(D-002) 반영.

### 주요 컴포넌트

- C-010, C-009, C-003, C-012(결과 없음), C-013.

### 상태 정의

- loading_initial: 검색/조회 중.
- empty: 결과 없음(조건 완화 제안).
- offline: 캐시 기반 결과만, 범위 안내.
- recoverable_error: 조회 실패 재시도.
- stale: 캐시 데이터 안내.

### 이벤트 정의

- `search.query`(FR-SEARCH-001), `filter.apply`/`filter.reset`(FR-SEARCH-002)
- `result.openComplex` → D-003, `result.showOnMap` → D-002

### 권한/정책

- 노트 검색 결과는 워크스페이스 범위(RLS). 공공데이터 조회는 프록시 경유(FR-DATA-004).

### 구현 메모

- 필터 시트는 하단 시트로 한 손 조작. 적용 전/후 결과 수 미리보기 권장.

## D-008 즐겨찾기/후보 리스트

### 화면 목적

관심 단지를 모으고 후보로 관리하며 비교(D-006)로 연결한다. (FR-FAV-001/002)

### 진입 경로

- 탭3(즐겨찾기). D-003 즐겨찾기 토글의 결과 반영.

### 레이아웃 구조

- 상단: 정렬/그룹, 비교 시작 액션.
- 본문: 즐겨찾기 단지 리스트(C-003), 다중 선택 후 D-006 비교.

### 섹션 정의

1. 즐겨찾기 목록(FR-FAV-001).
2. 후보 선택·비교 진입(FR-FAV-002 → F-007).

### 주요 컴포넌트

- C-003, C-004(노트 별점 요약), C-012(즐겨찾기 없음), C-015.

### 상태 정의

- empty: 즐겨찾기 없음(지도에서 추가 유도).
- loading_initial: 목록 로딩.
- offline: 캐시 목록 열람.
- partial_failure: 일부 단지 데이터 누락.

### 이벤트 정의

- `favorite.list`, `favorite.remove`(FR-FAV-001)
- `candidate.select`/`compare.start`(FR-FAV-002) → D-006

### 권한/정책

- 즐겨찾기는 워크스페이스 공유 자원(RLS). 부부가 함께 후보 관리.

### 구현 메모

- 비교 진입 시 최소 2개 선택 검증(D-006 empty 상태와 연결).

## D-009 워크스페이스/공유·초대

### 화면 목적

워크스페이스 멤버를 관리하고 초대/공유하며 계정 연결을 처리한다. (FR-WS-001~004, FR-AUTH-004)

### 진입 경로

- D-011 설정 → 워크스페이스, 알림 딥링크(F-002 초대), D-001 초대 수락 후.
- push(독립 탭 아님).

### 레이아웃 구조

- 상단: 워크스페이스명, 멤버 아바타 C-015 목록.
- 본문: 멤버 관리(초대/제거), 초대 링크/코드 생성·공유, 계정 연결(FR-AUTH-004), 워크스페이스 설정(FR-WS-004).

### 섹션 정의

1. 워크스페이스 정보·멤버(FR-WS-001).
2. 초대 발송/수락(FR-WS-002, F-002).
3. 공유·실시간 협업 설정(FR-WS-003).
4. 워크스페이스 관리/계정 연결(FR-WS-004, FR-AUTH-004).

### 주요 컴포넌트

- C-015, C-012(멤버/초대 없음), C-013.

### 상태 정의

- loading_initial: 멤버/초대 로딩.
- operation_pending: 초대 발송/수락 처리.
- no_permission: 비소유자가 관리 액션 시도(권한 안내).
- recoverable_error: 초대 실패 재시도.
- offline: 관리 액션 제한 안내.

### 이벤트 정의

- `member.list`, `invite.create`(FR-WS-002), `invite.accept`(F-002)
- `member.remove`, `workspace.update`(FR-WS-004)
- `account.link`(FR-AUTH-004)

### 권한/정책

- 부부 2인 멤버 상한(FR-WS-*). 관리 권한은 소유자 정책(no_permission 상태).
- RLS 워크스페이스 격리(NFR-002).

### 구현 메모

- 초대 링크는 F-002 딥링크와 일치. 미인증 수락은 D-001 경유 후 복귀.

## D-010 알림 센터

### 화면 목적

코멘트·초대·동기화 관련 알림을 모아 보여주고 딥링크로 대상 화면에 이동한다. (FR-NOTIFY-001~002)

### 진입 경로

- 탭4(알림). 푸시 알림(Expo Notifications) 탭 → 딥링크(F-008).

### 레이아웃 구조

- 상단: 읽음/안읽음 필터.
- 본문: 알림 리스트(유형 아이콘, 작성자 C-015, 시간), 항목 탭 → 대상(F-008).

### 섹션 정의

1. 알림 목록(FR-NOTIFY-001).
2. 알림 설정/구독(FR-NOTIFY-002, 세부 설정은 D-011 연계).
3. 딥링크 라우팅(F-008).

### 주요 컴포넌트

- C-015, C-012(알림 없음), C-013.

### 상태 정의

- loading_initial: 알림 로딩.
- empty: 알림 없음.
- offline: 캐시 알림 열람, 신규 수신 지연.
- recoverable_error: 로딩 실패 재시도.

### 이벤트 정의

- `notify.list`, `notify.markRead`(FR-NOTIFY-001)
- `notify.openTarget`(F-008) → D-012/D-009/D-005 등
- `notify.subscribe`(FR-NOTIFY-002)

### 권한/정책

- 알림은 워크스페이스 범위. 딥링크 대상 권한 없음/삭제 시 no_permission/not_found 처리(F-008).

### 구현 메모

- 딥링크 대상이 사라진 경우 안전한 폴백 화면 제공(상태 매트릭스 참조).

### 주요 컴포넌트

### 상태 정의

### 권한/정책

### 구현 메모

## D-012 노트 상세/코멘트

### 화면 목적

노트를 열람하고(체크리스트·사진·본문) 코멘트로 부부가 대화한다. 노트 수정/삭제 진입을 제공한다. (FR-NOTE-002/004/006, FR-COMMENT-001, FR-MEDIA-002)

### 진입 경로

- D-005 피드, D-003 단지 노트, 알림 딥링크(F-008), 검색 결과에서 push.

### 레이아웃 구조

- 상단: 단지·작성자 C-015·별점 C-004, 편집/삭제(FR-NOTE-006).
- 본문: 체크리스트 보기 C-005(읽기, FR-NOTE-002), 사진 갤러리 C-006(FR-MEDIA-002 열람), 본문 메모(FR-NOTE-004).
- 하단: 코멘트 스레드 C-007(FR-COMMENT-001), 코멘트 입력.

### 섹션 정의

1. 노트 헤더·작성자(FR-NOTE-006 편집 진입).
2. 체크리스트 열람(FR-NOTE-002).
3. 사진 열람(FR-MEDIA-002).
4. 본문(FR-NOTE-004).
5. 코멘트(FR-COMMENT-001, F-004).

### 주요 컴포넌트

- C-004, C-005, C-006, C-007, C-015, C-013, C-012(코멘트 없음).

### 상태 정의

- loading_initial: 노트/코멘트 로딩.
- empty: 코멘트 없음(첫 코멘트 유도).
- operation_pending: 코멘트 전송/동기화.
- offline: 코멘트 로컬 큐, 동기화 대기(C-013).
- partial_failure: 사진 일부 로드 실패 분리 표시.
- stale: 실시간 코멘트 갱신 끊김.

### 이벤트 정의

- `note.load`, `note.edit`(FR-NOTE-006) → D-004, `note.delete`
- `photo.view`(FR-MEDIA-002)
- `comment.add`/`comment.realtime`(FR-COMMENT-001, F-004)

### 권한/정책

- 본인 워크스페이스 노트만 열람/코멘트(RLS, NFR-002). 삭제는 작성자/소유자 정책.

### 구현 메모

- 코멘트는 Realtime 구독. 오프라인 코멘트는 동기화 큐 후 재전송(F-003 연계).
