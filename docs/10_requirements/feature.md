# 임장노트 기능 후보 문서

## 1. 목적

이 문서는 임장노트의 후보 기능을 수집하고 정규화한다. 이 문서는 승인된 범위가 아니며, `srs_final.md` 또는 `prd.md`에 반영된 항목만 구현 범위가 된다. 상태는 `승인`(SRS 반영), `후보`(검토 중), `보류`(후순위), `제외`(범위 밖) 중 하나다.

## 2. 출처/근거 코드

| 출처 ID | 설명 |
| --- | --- |
| SRC-USER | 사용자(부부 임장 사용자) 직접 요구 |
| SRC-DOMAIN | 부동산 임장 도메인 일반 관행 |
| SRC-GOV | 국토교통부 공공데이터 OpenAPI 명세 |
| SRC-MAP | Kakao Map SDK/REST 기능 |
| SRC-SAAS | 일반 SaaS 품질 기준(인증·권한·감사·관측) |

## 5. 실현 방식 분류 기준

- Type A: 클라이언트 로컬 또는 기존 설정으로 구현 가능.
- Type B: Supabase(테이블/RLS/Edge Function) 또는 외부 API 연동 필요.
- Type C: UX 재설계 또는 오프라인/충돌 등 복잡 로직 필요.
- Type D: 정책상 제외 또는 후순위.
