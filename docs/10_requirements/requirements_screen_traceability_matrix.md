# 요구사항-화면 추적 매트릭스

## 1. 목적

본 문서는 `srs_final.md`의 요구사항 ID를 `imjang_note_*` 파생 문서군의 화면 ID와 연결한다.

## 2. 사용 원칙

1. 기능 기준은 `srs_final.md`다.
2. 화면 ID 기준은 `../20_derived_ui_specs/imjang_note_product_ia.md`와 `../20_derived_ui_specs/imjang_note_wireframe_spec.md`다.
3. 하나의 요구사항은 하나 이상의 화면 ID와 연결될 수 있다.
4. UI가 직접 없는 요구사항(동기화·캐시 등)도 상태·설정·노트 화면 등 간접 노출 지점으로 연결한다.

## 5. 검증 메모

- 모든 요구사항 ID는 `srs_final.md` 또는 `prd.md`에 존재한다.
- 모든 화면 ID(D-001~D-012)는 `imjang_note_product_ia.md`와 `imjang_note_wireframe_spec.md`에 정의되어야 한다.
- 비-UI 요구사항(FR-DATA-003, FR-SYNC-*, NFR-*)은 상태/설정/노트 화면으로 간접 연결했다.
